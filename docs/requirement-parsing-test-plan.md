# 需求文档解析质量测试用例集（STO / TS / EN 16314 / SBD）

日期：2026-07-30
目标：验证需求解析对比工具对四类文档"分析清楚、不遗漏、分段分块清晰、影印明了"。
方法：**工具解析产物为被测对象（SUT），期望值来自对文档的确定性直接探测**（不依赖
工具的独立计数/抽样人工核对）+ 自一致性回归（重复运行产物稳定）。

## 0. 测试文档基线（确定性探测值，2026-07-30）

| 文档 | 格式 | 特征 | 探测基线 |
|---|---|---|---|
| STO_34.01-5.1-009-2024 | docx | 俄标 GOST 风，大参数表 | 164 blocks；4 表（术语 54 行、参数 143/153 行、需求清单 41 行）；规范主体在表 |
| TS - Novy Nepriamy elektromer 0,2 S | pdf | 标书技术规格 | 46 节；7 条合规交付块；表格中量 |
| EN 16314:2013 Gas meter | pdf | EN 标准，附加功能 | 1141 blocks；16 表；347 requirement_like 块 |
| SBD ZETDC STS 预付费电表 | pdf | 标书，表格密集 | 899 blocks；**91 表**；347 requirement_like 块 |

## 1. 测试维度与度量口径

- **D1 分段分块**：块结构完整、类型正确、边界不错位（标题不吞正文、表格不切碎）
- **D2 抽取完整性（不遗漏）**：覆盖分母、行级展开命中、合规召回、漏抽登记闭环
- **D3 解析正确性**：引句逐字率、数值/编码零漂移、需求-来源映射正确
- **D4 影印视图**：页图齐全、几何锚定覆盖、行级热区、点击-右栏一致
- **D5 确定性回归**：同输入重复运行产物逐字节一致（缓存路径 vs 重算路径）

## 2. 用例集（每文档执行 P0 全部 + P1 抽样）

### TC-01【STO docx】块结构与行级完整（P0）
- 步骤：`ratomizer atomize --input STO.docx --out out/sto`
- 期望：164 blocks；4 个 table 块；参数表 data_rows=143/153/41/54；block 类型无 `unknown`
- 判定：确定性比对（脚本断言计数与行数）

### TC-02【STO】参数表逐行展开（P0）
- 步骤：atomize + ai-extract（stub 即可——确定性展开不依赖 LLM）
- 期望：参数表每行 ≥1 条 PROW-DET draft；引句逐字率 = 100%；分组标题行 0 条；
  术语表 0 条需求（裁定点）
- 判定：自动断言（引句 ⊆ 块文本、行号连续无重复）

### TC-03【STO】行级抽取无双份（P0，需 LLM）
- 步骤：ai-extract --llm-route openai_compatible
- 期望：同渲染行无 LLM 需求 + PROW-DET 双份；`merge_trace` 审计行存在
- 判定：自动断言（key_cell 重合检测 = 0 双份）

### TC-04【STO】影印行级视图（P0，需本机 Office）
- 步骤：export-annotation-html → 打开批注视图
- 期望：82 页页图；术语表 ≥50 行热区；点第 1 行出第 1 行卡（不串行）；行卡含
  原文 + 「解析此行」
- 判定：自动（几何文件行区数 + 页码分布断言）+ 人工抽 3 行点验

### TC-05【TS pdf】合规交付全召回（P0）
- 步骤：全链运行
- 期望：合规块覆盖 7/7；证书类 `compliance_instrument` 正则命中（STN EN 62053-22）
- 判定：自动断言

### TC-06【TS】引用三层分流（P0）
- 期望：「引用标点差异」「引用跨段」只进参考区；必答区无软标
- 判定：自动（澄清报告 tier 分布断言）

### TC-07【EN 16314】章节/清单结构（P1）
- 期望：16 表结构正确（Abbreviations 表 4 行、Solar Radiation 表 2 行）；
  清单块 list_role 标记正确（intro/item 不错标）
- 判定：自动断言 + 抽 2 节人工看分块

### TC-08【SBD】表格密集文档完整性（P0，重点压力用例）
- 步骤：全链运行（**预期耗时最长，监控 atomize 耗时**）
- 期望：91 表全部成块、无解析失败单元；需求型表逐行展开率 ≥90%；
  `failed_sections = 0`
- 判定：自动断言；atomize 耗时记录入报告（性能回归观察项）

### TC-09【SBD】91 表型分布核查（P1）
- 期望：classify_table_kind 判定结果人工抽 10 表复核（参数/术语/其他无错分）
- 判定：人工抽样（映射表若出现，按 Phase 3 后置口径记录，不强行按格）

### TC-10【全部】重复运行确定性（P0）
- 步骤：同输入同配置运行两次（首跑 vs 缓存续跑 + 清缓存重算）
- 期望：blocks.jsonl / ai_requirements.jsonl 逐字节一致（除时间戳字段）；
  指纹命中时第二阶段 skipped
- 判定：自动 diff（排除 generated_at 字段）

### TC-11【全部】影印页码-右栏一致性（P1）
- 期望：任点 5 处（表行/段落），右栏块/行卡与左页位置对应；
  无"点 A 出 B"
- 判定：人工抽样（影印已知修复点回归）

### TC-12【全部】澄清聚合无海啸（P0）
- 期望：行级 suspicion 按表聚合（每表 ≤1 条/类）；必答总数相对旧基线 ≤2x
- 判定：自动断言

## 3. 执行与记录

- 自动化部分：建议落 `tests/test_document_quality_gate.py`（参数化四文档路径，
  机器本地路径经 env 注入，缺席如实 skip）；
- 人工部分：本文件勾选记录（每用例 通过/失败/样本截图位置）；
- 性能观察：atomize/几何解析耗时入记录表（当前基线：STO atomize 203s、
  行级几何 71.5s）。

## 4. 判定总门槛

P0 全过 = 文档可交付评审；任一 P0 失败 = 阻断，先修后放。P1 失败 = 记录并限期修。
