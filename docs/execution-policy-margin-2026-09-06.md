# EXECUTION_POLICY 边际价值重估（2026-09-06）

当前生产默认已经是功能需求直抽，`quality_first` 相比 `legacy_combined` 的主要增量不再是“是否使用功能需求”，而是是否强制按单元路由编排 A/B 轨、是否执行双轨审计，以及是否把路由缺口自动升级为定点复核任务。

本轮改造后仍维持 `legacy_combined`，原因是门禁证据尚未闭合：真实语料的表格 preservation/绑定问题仍有未分类项，WS0 功能真值集也没有形成可重复的多文档通过基线。此时翻转策略会把未完成的输入质量问题变成默认执行差异，不能提供可解释的收益。

保留翻转的明确触发条件：

1. 任务 D 的表格失败项完成 a/b/c 归类，并对 c 类确认由 cell 级守恒接管；
2. 新真值集在 A/B 两腿上完成多文档复跑，覆盖率、保真率、重复率和行增长阈值全部有报告；
3. `quality_first` 的路由缺口、局部重抽和成本记账在同一结果包中可复核；
4. 翻转前后保留一轮 `legacy_combined` 对照，证明收益来自策略差异，而不是输入或模板变化。

在这些条件满足前，`quality_first` 继续作为显式试验/诊断策略，`legacy_combined` 作为生产默认；不以单测全绿、已有 XLSX 文件存在或单文档成功替代真实语料门禁。
