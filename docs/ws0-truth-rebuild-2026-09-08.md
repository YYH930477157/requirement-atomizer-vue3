## 验证暴露的两层更深断层（v2 × 注入产物仍 TP=0）

1. **粒度断层**：真值行=段落/子节级综述（数字/单位积累横跨整个子节），产物=一条款
   一完整需求（v5 契约）。`_evaluate_pair` 的 eligibility 要求单行 coverage≥0.5 且
   零冲突——段落级真值对单条 FRE 结构性不可满足（最佳对 0.44，冲突清单 8+）。
2. **形态/词汇断层**：分析师英文是**归一化转述**（翻译体），产物叙述贴**源文破碎
   英语**（quote-verbatim 契约）——同一内容的 token 重叠仅 0.2~0.4。且真值主体是
   解读式注释形态（"It corresponds to…"），非需求句枚举；含 must/shall 的规范式行
   106/189、b_track 域内 39/67。

**结论：三层断层（语言[已修]→粒度→形态）中后两层不是参数问题，是「真值工件形态」
与「门禁匹配假设」的根本错配。继续调匹配器旋钮=逐项放宽 M3 刻意从严的语义，属
审核方决策，不宜工程侧单方面推进。**

## 方案选项（呈报裁定）

| 方案 | 内容 | 代价/风险 |
|---|---|---|
| **A 语义对齐层（推荐）** | 保留 v2 英文真值为权威；匹配层加一步**语义等价判定**（LLM judge 或 embedding 近邻）做 truth↔row 候选配对，token 匹配仅作确定性兜底/复核；判定结果可缓存可审计（每对带理由落盘） | 新增一层判定器（有成本）；需钉「宁漏勿错」的判定纪律（无把握=不匹配）；不放宽既有冲突/覆盖语义，只换对齐方式 |
| B 真值句子级拆分+阈值放宽 | 按句拆真值 + coverage 门槛下调 + 冲突按句域重算 | 每个旋钮都是语义放宽；碎片化真值失分析师段落语义；不解决词汇归一化断层（原型实测句级仍 0 命中） |
| C 样本化人工验收 | 放弃全量 truth 匹配：守恒门（已全绿）+ 从 v2 真值分层抽样 N 条走既有 claim/专家复核流做人工验收率 | 门禁从全量指标退化为抽样证据；14 阈值口径需重定义 |
